# Build contract

`PRODUCT.md` is the concise product and UX contract for this standalone repository. The implementation order is fixed:

1. Independent Convex schema and Wisconsin race manifest.
2. SerpApi Account API guard, political-ad capture, and source-linked Ad Passport.
3. Google News and shared-query Google Trends captures; reactive Voter Radar layer states.
4. Stored snapshot comparison and transparent reportability rules.
5. Press Desk filters, provenance drawer, and source-bundle export.
6. `gpt-5-mini` evidence investigator constrained to stored Convex records.

No Clerk, SignalGap imports, user accounts, political recommendations, or client-side API keys belong in this project.
